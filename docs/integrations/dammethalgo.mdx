Lagoon API. It is an algorithmic, rule-based liquidity-provision fund. See
[Integrations](./index.mdx) for the endpoint, conventions, and response shapes shared
by all funds.

## 1. Core state, fees & APRs

```bash
curl -s -X POST https://api.lagoon.finance/query \
  -H "Content-Type: application/json" \
  -d '{"query":"{ vaultByAddress(address:\"0xe6f4bc20f08125818baaac57e6f398ffadcb8d28\", chainId:1) { name symbol asset { symbol priceUsd } curators { name } state { totalAssets totalAssetsUsd totalSupply pricePerShare pricePerShareUsd managementFee performanceFee protocolFee entryRate exitRate isPaused syncMode accessMode weeklyApr { twrrNetApr linearNetApr } monthlyApr { twrrNetApr } yearlyApr { twrrNetApr } } } }"}'
```

- **Monetary fields are dual**: raw on-chain `BigInt` (`totalAssets`,
  `pricePerShare`, where WETH has 18 decimals) plus a convenience `…Usd: Float`.
  Track performance in the native series (`pricePerShare`), not the USD
  variants.
- **Fees are basis points** (1e4 = 100%). Current configuration:
  `managementFee: 0`, `performanceFee: 0`, `protocolFee: 1000` = 10% (of
  collected fees), no entry/exit fees.
- `weeklyApr.twrrNetApr` = time-weighted net APR; `linearNetApr` = simple.
  Both are already in percent (e.g. `4.99` = 4.99%).
  A `null` APR means insufficient recent settlement data for that window.

## 2. Historical time series

`stateHistory` returns an ascending series of `{x: unixSeconds, y: value}`
points (max 1000 per field). Pass an optional
`options: {startTimestamp, endTimestamp}` window.

```bash
curl -s -X POST https://api.lagoon.finance/query \
  -H "Content-Type: application/json" \
  -d '{"query":"{ vaultByAddress(address:\"0xe6f4bc20f08125818baaac57e6f398ffadcb8d28\", chainId:1) { stateHistory { pricePerShare(options:{}) { x y } totalAssetsUsd(options:{}) { x y } } } }"}'
```

Other series under `stateHistory`: `totalAssets`, `totalSupply`,
`pricePerShareUsd`, `managementFee`, `performanceFee`, `protocolFee`,
`highWaterMark`. One point lands per settlement. Cadence is irregular (gaps from under a day
to several weeks), so check the last point's `x` for the NAV's age.

## 3. Transaction / event history

Every indexed event: deposits, redeem requests, settlements, fees taken and
rate updates. Filter with suffix operators (`_eq`, `_in`, `_gte`, …);
paginate with `first` + `skip`.

```bash
curl -s -X POST https://api.lagoon.finance/query \
  -H "Content-Type: application/json" \
  -d '{"query":"{ transactions(first:10, skip:0, orderBy:timestamp, orderDirection:desc, where:{ vault_in:[\"0xe6f4bc20f08125818baaac57e6f398ffadcb8d28\"], chainId_eq:1 }) { pageInfo { totalCount } items { type timestamp hash blockNumber } } }"}'
```

- Useful `where` filters: `type_in: [Deposit, SettleDeposit, FeeTaken,
  RedeemRequest]`, `timestamp_gte`, `owner_in`, `controller_in`.
- A depositor's money leaves their wallet at `DepositRequest`; the `Deposit`
  event fires later, at claim time. Date flows from `DepositRequest`.
- A redeem's share burn appears as a `Transfer` to the vault's pending silo
  (`0xe1babd0324a5b91b4808f5b6363a103133d26c7f`), not to a third-party
  counterparty.

## Caveat: composition data is incomplete

:::warning DAMMethAlgo uses several Safes, and Lagoon only sees some of them
DAMMethAlgo runs capital across several Safes, including a mother Safe and
Aerodrome LP children on Base (v1.1). Lagoon's `composition` feed covers only
part of this, recently about 40% of TVL, so `composition.totalValueInUsd` runs
well below `state.totalAssetsUsd`.

✅ Use `state.totalAssets` / `totalAssetsUsd` and `pricePerShare` for fund size
and share price. ❌ Do **not** treat `composition` as a complete allocation
picture for DAMMethAlgo.
:::
