DAMM Capital builds and operates quantitative financial infrastructure onchain. We research, build and deploy financial vehicles that run autonomously through smart contracts. Every vehicle is transparent, permissionless and fully auditable.

The name comes from our founding idea: **Decentralized Autonomous Money Management (DAMM)**. It is a framework for managing capital in a transparent, efficient and trust-minimized way.

## Two verticals, one engine

The same engine runs both sides of DAMM.

- **Tokenized funds.** Non-custodial funds for USD, ETH and BTC, run by DAMM. See [Funds](./funds/index.mdx).
- **DeFi as a Service (DaaS).** Integrations that take fintechs and institutions into DeFi: liquidity management, curation, execution and research. See [Introduction](./introduction.md).

Both run on the **DAMM Toolkit**, our onchain fund architecture built on Safe, Zodiac Roles and Lagoon. Clients keep custody. DAMM manages within limits enforced by code.
